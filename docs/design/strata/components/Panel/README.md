# Panel

Bloc de contenu titré sur `surface-1` avec bordure `line` et rayon `radius-lg` : la brique de toutes les pages.

- Titre `section-title` (14 px dans les colonnes latérales, 16 px dans la colonne principale), sous-titre facultatif, actions à droite.
- `padded={false}` pour un corps qui contient un tableau ou une liste à lignes séparées.
- Les panneaux se séparent par l'espace (`space-4` à `space-6`), jamais par une ombre.
- Pas de panneau dans un panneau : à l'intérieur, utiliser des séparateurs `line-subtle`.
