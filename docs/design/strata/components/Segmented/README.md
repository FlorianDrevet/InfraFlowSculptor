# Segmented

Choix exclusif entre deux à quatre options courtes, visibles d'un coup : environnement affiché, exposition (Publique, Publique restreinte, Privée), stratégie de déploiement, mode de publication.

- Au-delà de quatre options, ou si les libellés sont longs, utiliser une liste déroulante.
- `mono` quand les options sont des identifiants (environnements).
- Le changement s'applique tout de suite à l'affichage ; une valeur du modèle part avec « Enregistrer ».
- Ne pas l'utiliser pour naviguer entre sections d'une page : c'est le rôle de `Tabs`.
