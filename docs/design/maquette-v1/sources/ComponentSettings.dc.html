platform
Unique : déployé une fois, dans sa cible propre. Les composants par environnement peuvent s'y relier ; l'inverse est refusé.
Sans objet pour un composant unique. Sur connectivity : dev → sub-connectivity-nonprod, prd → sub-connectivity-prod.
Ressources retirées du modèlePour les ressources à données. Une cible protégée détache toujours. Les accès et la configuration retirés sont toujours révoqués, en production aussi.
Refus de suppression de la pile : personne ne peut supprimer les ressources gérées ni leurs accès, sauf l'identité de déploiement, qui peut ainsi révoquer. Aucun verrou Azure n'est posé.
Désactivé : les gabarits du projet s'appliquent.
Supprimer le composant Refusé : orders a une liaison vers cr main. Retirez-la d'abord. Une fois possible, la suppression d'un composant déployé le met en « retrait demandé » : chaque cible déploie une unité vide, révoque ses accès et confirme. Les données restent dans Azure, à l'inventaire des ressources détachées.
